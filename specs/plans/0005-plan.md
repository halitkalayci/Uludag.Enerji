## Risks & open questions
- **Ortam:** `./scripts/doctor` → `profile fast: runnable`, `profile full: runnable`; tüm önkoşullar
  karşılanıyor. SDK 10.0.401 kurulu, hedef `net9.0` (CI ile aynı).
- **R-1 Yeni paket `Microsoft.CodeAnalysis.CSharp`:** MIT, Microsoft bakımlı, CVE yok (BUILD'de
  `dotnet list package --vulnerable` ile doğrulanır). **Öneri:** kabul — kaynak koddan okuma, çözüm
  derlenmiyorken de çalışmayı (R-1, AC-1) sağlar; regex ile ayrıştırma kırılgan, reflection derleme ister.
  Sürüm .NET 9 SDK ile uyumlu en son 4.x kararlı sürüme sabitlenir.
- **R-2 CLI kütüphanesi:** `System.CommandLine` hâlâ beta/yeni API'li. **Öneri:** elle ayrıştırma — 2 komut,
  5 seçenek; ikinci bir bağımlılık gereksiz.
- **R-3 Şablon motoru:** Scriban vb. yerine C# raw string. **Öneri:** raw string — ek paket yok, derleyici
  kontrolü var; bedeli şablon değişince yeniden kurulum (`install.sh`), kabul edilebilir.
- **R-4 Kayıt dosyalarına metin ekleme:** dosyalar elle değişirse çapa kaybolabilir. **Öneri:** çapa
  bulunamazsa hiçbir dosya yazılmaz, hangi dosyada hangi çapanın arandığı yazılır; testler gerçek repo
  dosyalarının kopyası üzerinde koşar, böylece dosyalar değişirse test kırılır.
- **R-5 Derleme testi süresi:** geçici kopyada `dotnet build` ~30–90 sn. **Öneri:** `Category=Integration`
  (full-only, docs/testing.md "Two speeds 3"); `-nodeReuse:false -p:UseSharedCompilation=false` (resource
  hygiene); kopya repo dışında (`Path.GetTempPath()`), `bin/obj` hariç, `finally` ile silinir.
- **R-6 docs ↔ spec çelişkisi (R-10) — mesaj anahtarları:** spec "Product düzeni" diyor; ama
  `docs/conventions.md` kullanıcı mesajlarını `<Feature>Constants` anahtarı + `Locales/<Feature>Locale.{tr,en}.yaml`
  ile istiyor (Order böyle, Product değil). **Öneri:** belgedeki kuralı izle (Order kalıbı) → `XConstants`
  + 2 yaml; dosya sayısı 13 → 16. Spec R-2/AC-2 buna göre güncellenir. Not: yaml'lar bugün çalışma
  zamanına bağlı değil (Order'da da öyle) — mevcut durum, bu spec'in konusu değil.
- **R-7 docs ↔ spec çelişkisi (R-10) — `UserId`:** spec "FK Guid korunur" diyor; `docs/conventions.md` ise
  kimliğe bağlı alanların (UserId) istemci gövdesinden alınmamasını istiyor. **Öneri:** `UserId` adlı
  özellik Create/Update komutlarına girmez (Response'ta kalır); çıktıda "sunucuda oturumdan atanmalı"
  uyarısı. Diğer FK'ler korunur. Tarih/toplam gibi alanları araç ayırt edemez → çıktıdaki sonraki adımlar
  genel bir hatırlatma içerir. Spec R-4/AC-6 buna göre güncellenir.
- **R-8 Dal:** Şu an `fix/a1-login-divide-by-zero` dalındayız; spec ve plan dosyaları commit'lenmemiş.
  **Öneri:** BUILD başında `main`'den `feature/0005-crud-generator-cli` açılır, iki dosya oraya taşınır ve
  ilk commit'e girer. Gerekçe: docs/git.md — spec başına dal, başka işin dalına karışmaz.
- **R-9 AC-3/AC-4 çalışma zamanı kanıtı:** VERIFY, atılan `tmp/0005-smoke` dalında: fixture entity ekle →
